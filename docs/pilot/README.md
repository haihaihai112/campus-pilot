# CampusPilot 分批试用工作包

目标：武汉理工大学2026级本科生累计真实使用5人 → 15—20人 → 50—70人。人数是累计提交真实需求的人数，不是并发承诺。当前已验证[本机临时HTTPS入口](HTTPS_LOCAL.md)，需求确认仍待实际记录；没有已完成访谈或真实学生使用证据。

现在先使用 [访谈记录](interviews.md) 和 [场景与资料缺口](scenarios-and-sources.md)。完成5份匿名访谈后，选择重复出现、能获得官方依据的2—3个场景。场景尚未选定；没有需求依据就调整定位，暂不扩邀。

文件导航：

| 文件 | 用途 |
|---|---|
| interviews.md / interviews-template.json | 5份空白访谈；JSON供本地整理 |
| scenarios-and-sources.md / source-review.json | 场景筛选、缺口及4份来源复核工作表 |
| operations.md | 账号分类、统计、费用、排队、备份与部署检查 |
| trial-and-gates.md | 学生体验说明、逐批放行条件、暂停和回滚 |
| ../../evaluation/pilot/README.md | 30条待独立复核案例及先5条真实模型检查流程 |
| SOURCE_REVIEW_2026-10-18.md | 4页重新读取与正文比较；政策持续有效性仍未确认 |

模板中的pending/null是待完成事项。将填写副本放入被Git忽略的runtime目录，避免提交学生对话、账号或反馈原文；只将核对后的匿名汇总用于展示。不要向学生收集密码、身份证、录取通知书或无关的家庭经济细节。

本地测试只能证明程序机制。公开网页快照、fixture通过和人工运营复核分别记录，不能写成实时校方政策、模型正确率或真实用户成果。当前不增加Agent、知识图谱、Redis或长期记忆，也不新增公开业务API。
