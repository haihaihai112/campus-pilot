# 5人需求访谈

每人约10分钟。对象为武汉理工大学2026级本科生，是否符合由本人自述，不收学号证明。组织者自行联系愿意参与的学生；本项目没有自动招募或发送消息。

开场（1分钟）：说明这是个人项目的需求访谈，可以跳过或结束；仅记录匿名问题摘要，不录入姓名、账号、身份证、密码和无关资助详情。

先问现状（5分钟），再介绍CampusPilot（2分钟），最后复述确认（2分钟）：

1. 最近两周还有哪件入学相关事情没解决？最近一次是什么时候遇到的？
2. 当时从哪里找资料、问了谁？哪个步骤最费时间或最不确定？
3. 目前已经解决了什么，还有什么要继续处理？如果已无需要，如实记录。
4. 介绍“按公开来源回答、整理清单、确认后保存个人待办”后，再问：其中哪一项能解决你刚才的问题？为什么？
5. 哪份资料、哪个条件缺失，会让你无法使用？你是否愿意随后自愿试一次？不要求创建日历。

不要先暗示“你需要入学规划吧”。明确区分当前未解决事务、过去报到经历和仅用于展示的假设问题。正反反馈均保留。
