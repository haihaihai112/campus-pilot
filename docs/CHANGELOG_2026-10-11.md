## 修复过程与失败记录

首次使用单独测试目录时，其父目录未建立，导致 59 项测试环境初始化错误；创建父目录后复跑 73 项全部通过。该错误记录保留在 [首次 XML](../reports/campuspilot-tests-2026-10-11.xml)。

随后扩展到 75 项，一项本人会话恢复断言把 SSE 中的 JSON Unicode 转义当作原始中文字符串检查，导致 74 项通过、1 项失败；实际会话返回成功。改为 JSON 解析后断言原始内容，最终 75/75 通过。失败记录保留在 [修复前 XML](../reports/campuspilot-tests-2026-10-11-final.xml) 与对应日志。

升级账号归属时还发现原单用户测试会话缺少 user_id；增加演示身份的兼容读取，试用账号仍无法访问演示用户记录。

## 下一步与结果边界

目标是约 50—100 人邀请体验，目前没有真实用户采用记录，也未完成该规模的负载实测。建议先用 5—10 名真实体验者和有效模型配置验证自由表达、误答与费用，再逐步扩展。

当前是一台主应用、一个 Uvicorn 进程；限额持久化，但队列和并发信号量在进程内。MCP/A2A 属于私有受信任服务，身份隔离由主应用执行，不宣称独立多租户服务端安全。远程使用需配置 HTTPS、开启 Secure Cookie 并保存备份。

校园资料仍是合成演示数据，不用于真实高校报到决策。Milvus、地图天气真实接口与个人平台日历均未在本轮验证。现有历史真实模型记录只证明旧基线端到端链路，不替代新版本真实模型复测。
