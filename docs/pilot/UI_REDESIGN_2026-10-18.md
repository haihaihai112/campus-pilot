# 2026-10-18 简洁界面改造

此文为对应阶段的历史记录；后续实现状态与本次发布验证以 README 和 docs/PUBLICATION.md 为准。
按用户要求采用白底、深蓝文字：左侧以对话和输入为主，右侧介绍清单、待办、个人日程与导出。登录页统一样式。手机端纵向排列，功能介绍放在对话下方。

## 操作流程

1. 提问或说明事务，按 Enter 发送；Shift + Enter 换行。
2. 助手咨询、追问或生成内容，待确认操作出现时才显示保存区域。
3. 展开“查看待保存内容”核对，然后确认保存或先不保存。
4. 从折叠区查看个人事项、历史、来源及反馈；地图天气和外部日历收在“更多工具”。

保存或拒绝后重新读取操作状态，完成的确认区域收起，结果提示保留在对话下方；可重试操作仍保留确认入口。

“新对话”和聊天清空按钮只重置当前页面会话，不删除历史或个人事项。原有邀请登录、服务端身份校验、独立规划 Agent、MCP/A2A 协议及确认写入机制继续使用。
